# 驾驶与道具规则 · v2

以《Mario Kart World》为玩法参考。原作常规视角为车后第三人称；本项目桌面和 VR 均默认第一人称驾驶位，桌面保留 C 键切换第三人称用于对照测试。双手柄模拟方向盘，不通过转头驾驶。出处和改编范围见 [DESIGN-REFERENCES.md](DESIGN-REFERENCES.md)。以下时间和数值是本项目调校，不是任天堂官方参数。

## 驾驶与速度反馈

| 参数 | 当前值 |
| --- | --- |
| 桌面普通最高速度 | 18 m/s（64.8 km/h），旧版 12 |
| 加速度 / 刹车减速度 | 12 / 22 m/s²，约 1.5 秒达到普通极速 |
| 松油门减速度 | 1.6 m/s² |
| 倒车 | 停稳继续刹车 0.5 秒，最高 4 m/s |
| 满转向半径 | 低速 3.8 米 → 10 m/s 以上 6.5 米 |
| 漂移半径 | 普通半径 × 0.8；普通 / 漂移最大偏航速度 110° / 150° 每秒 |
| 草地 / 减速区 | 最高速度 × 0.6 |
| 蘑菇加速 | 最高 26.1 m/s（94 km/h），加速度 × 2.5 |
| VR 速度系数 | 0.72，须真机调校；普通极速约 13 m/s |
| 双手方向盘 | 当前握持姿势校准中位，左右各 65° 达到满转向 |

车辆按转弯半径控制方向，普通转向角速度限制为 110°/秒，漂移为 150°/秒，变化速度限制为 300°/秒²。满转向时自动收速到约 12.5 m/s，保留约 6.5 米半径，避免高速瞬间转头；直线极速保持 18 m/s。键盘从中位到满方向约需 0.25 秒，松开约 0.17 秒回正。

横向抓地恢复加速度为 36 m/s²；保留受碰撞后的短暂侧滑，随后收回。车身的物理旋转锁定，车头朝向由转向控制，碰撞不能给玩家镜头附加旋转。撞墙时移除朝墙内的速度分量，保留沿墙速度；重叠解算速度限制为 2 m/s，避免车身被瞬间推出很远。贴墙接触期间持续限制向墙内加速，不给反弹脉冲。顶墙且速度不足 3 m/s 时，油门/刹车配合方向输入提供最多 55°/秒低速脱离转向。漂移开始后锁定左/右方向，同向输入收紧弯道、反向输入放宽弯道。

普通速度超过 6 m/s、接地时按住 Space：转向超过 0.2 进入漂移，否则蓄力跳跃。一次按住锁定模式。漂移 0.65 / 1.25 / 2.1 秒获得蓝 / 橙 / 紫三级火花；松开奖励 0.65 / 1.1 / 1.8 秒小加速。离地、低速或撞墙清空蓄力。直行蓄力 0.6 秒后松开，小跳高度 0.4 米，起跳间隔至少 1.55 秒。

桌面镜头：静止 FOV 65°，正常极速 76°，加速最高 86°；车后距离从 4.8 米平滑拉远到 5.6 米，加速再后退 0.8 米。没有突然跳变，镜头水平朝向平滑跟随。加速配合排气火焰、屏幕边缘速度线和引擎升调。

VR：保持真实头部追踪，不使用上述 FOV 动画、追踪位置后移或屏幕速度线。转弯和加速期间启用舒适暗角；车辆物理固定俯仰和侧倾，漂移倾斜只作用于外观。舒适性尚待真机验证。

## 道具

单槽库存；抽取 0.65 秒；箱子 5 秒刷新；满槽和抽取中拒绝拾取。测试箱显示固定类型，随机箱五种等概率（没有名次系统，暂不实现名次权重）。E 按下沿使用，最短间隔 0.25 秒。

| 道具 | 本项目规则 | 视觉反馈 |
| --- | --- | --- |
| 加速蘑菇 | 2.2 秒加速；可与短加速延长，不叠乘速度 | 红白蘑菇、橙色尾焰、视野扩张 |
| 超级星星 | 5 秒无敌，速度上限 × 1.25；免疫草地和受击减速；碰撞可使对手减速 | 星星环绕、车身彩色发光 |
| 绿龟壳 | 30 m/s 直线飞行，最多反弹 3 次，寿命 6 秒；命中速度 × 0.55、持续 1.2 秒 | 绿色旋转壳、绿色拖尾 |
| 香蕉 | 车后放置，0.5 秒布防，寿命 15 秒；命中速度 × 0.6、持续 1.5 秒；每车最多保留 2 个 | 三瓣黄色香蕉陷阱 |
| 冰之花 | 3 发冰弹；命中冻结减速 1.5 秒，速度 × 0.45，转向能力 × 0.6；撞墙消失 | 青色花朵、冰弹拖尾、车身冷光 |

龟壳反弹后可击中自己；香蕉布防后同样能伤到自己。无敌和受击保护阻挡攻击。受击后有 2 秒保护，避免连续惩罚；多重减速取最强，不连乘。加速带奖励 1 秒。

冻结/香蕉/龟壳采用减速和外观反馈，不强制旋转玩家视野。旧的单次护盾 API 保留供接入使用，已不在随机道具池中。

## 草地回场与路缘

现成道路放大后的路缘最高约 0.27 米。车辆使用中心与四个轮胎区域的接地射线，并以实际支撑接触兜底，避免横跨路缘时误判悬空。踩油门或倒车时，可通过最高 0.32 米的低路缘：确认台阶顶部可行驶、车身抬起后的空间无阻挡，再抬升车身；不施加弹跳冲量。护栏与高墙仍不可跨越，动态车辆不作为台阶。草地仍保留减速，回到道路恢复正常速度。

## 复位与边界

每帧记录车辆在赛道内时对应的中心线位置与沿赛道方向；驶离可用赛道范围后冻结这个位置。连续出界 1 秒，或在路缘附近持续踩油门/倒车却卡住 1.5 秒，自动短暂遮黑并返回该位置，车头沿赛道摆正。不是返回起点，也不采用驶出后继续移动到的草地位置。短暂擦边并在 1 秒内回到赛道会取消救援；暂停时计时停止。回场后有短暂宽限，避免连续触发。

长按 R 同样回到最近记录的赛道中心；没有配置 TrackRoute 的项目仍使用检查点。救援清除速度、加速、无敌、冻结、护盾和减速，保留未用道具。当前车辆适合平坦街机赛道与低障碍；陡坡、倾斜弯道须专门调校。

本次没有实现完整 AI、圈数排名、联网、墙面驾驶、轨道滑行或原作全部道具。现有靶车用于验证攻击与碰撞。

## 驾驶舱与驾驶节奏（2026-11-03）

- 默认第一人称：Keith 免费 CC0 完整车身，运动方向盘连接原车转向柱，数字仪表固定在前车罩；保留数字速度、10 段转速/漂移灯，道具显示在前车罩右侧。不显示虚拟手。方向盘最多可视旋转 85°，轮胎随车速滚动，前轮随转向转动。第三人称仍可用 C 切换。
- 油门、收油和高速使用 domasx2 的三层真实赛车音效交叉混音；刹车/漂移使用 Tom Haigh 的轮胎声音，草地用滤波后的滚动声。碰撞、道具、加速和三级漂移振动强度不同。音频归属保存在素材目录，暂停设置也显示署名。
- 辅助模式（默认）保留急弯自动收速；标准模式取消自动收速，仍保留轮胎侧向抓地和转向角速度限制，入弯过快会扩大半径。两个模式均保留碰撞稳定和自动回场。
- 漂移时侧滑速度最多 2.3 m/s，反打能减小侧滑与弧度；松开 Space 后用正常抓地力收回侧滑。三级蓄力仍为 0.65 / 1.25 / 2.1 秒，伴随不同音高与灯色。
- Enter 启动可重复的 3 秒起步练习，在 GO 前 0.8–0.15 秒之间开始持续给油，获得 1.4 秒起步加速。过早给油只有普通起步。比赛管理器可调用同一倒计时接口；自由练习不强制倒计时。
- 离地超过 0.08 秒后新按一次技能键可准备特技；有效腾空超过 0.16 秒、落地速度大于 4 m/s，奖励 0.8 秒加速。复位取消特技。
- 尾流：前车 3–14 m、横向差小于 1.8 m、同方向且均在行驶，无遮挡跟随 1.8 秒奖励 1 秒加速；3.5 秒冷却。对测试车/未来 AI 通用；不实现 AI 或排名计算。
- E 向前、Q 向后发射龟壳/冰弹；香蕉继续向后放置。命中后给发射者反馈。外部排名可启用道具权重：后位增加蘑菇/星星，前位偏香蕉；无排名时保持均匀随机。这是本项目自定义权重，不声称复制任天堂内部算法。
- Esc 设置：辅助模式、座椅高度、方向盘前后距离、方向盘灵敏度、VR 舒适暗角、重新校准。保存到本机 PlayerPrefs。
- VR 暂停时左 Primary 循环选项，左右扳机调整数值，右 Primary 切换开关或重新校准，右 Secondary 返回。真实头部姿态不叠加速度 FOV、摇晃或漂移滚转。直接使用左右手柄的位置计算方向盘输入；不生成虚拟手。

所有新增时间、距离和物理数值均是本项目调校值。设备未定，VR 按键、抓握距离、视野与舒适度仍需最终设备真机验收。

坡道接缝修正：roadBump 的入口柏油面由 0.220m 对齐到主路面 0.150m（模型下沉 2mm，避免共面闪烁），X 方向宽度从 5m 改为 12m，与主赛道一致；保留原有约 18° 坡度。这样原来位于车道内的坡道侧缘移到道路边缘。入口测试靶车移到旁侧，不再挡住上坡路线。

## 喇叭（2026-11-10）

H / 右手柄 primary2DAxisClick：点按短鸣、快速连按连续短鸣、长按持续鸣笛；取消触发冷却。点按至少发声 75ms，长按松开约 30ms 淡出。原始 CC0《Klaxon #1》稳定片段裁切并做 10ms 首尾交叉淡化，持续音使用单音源循环，避免叠音与尾部静音。每次按下轻震一次，长按不持续震动。仅用于趣味互动，不消耗道具或影响其他车辆。暂停/救援中停止并屏蔽；恢复时已按住的输入不补发。
